# Illustrasjoner

<Lead contributeBox={false}>
  Oslo kommune har utviklet en egen illustrasjonsstil som kommunens virksomheter
  kan benytte. Illustrasjonene er basert på osloformene, noe som gir dem
  egenart.
</Lead>

Virksomheter kan også benytte sine egne illustrasjoner. Hvis Oslo kommunes illustrasjoner brukes, skal de ikke blandes med andre illustrasjoner. Les mer om illustrasjonene i [designmanualen](http://designmanual.oslo.kommune.no/illustrasjoner).

Du finner [alle illustrasjonene i en egen Figma-fil](https://www.figma.com/file/cPiS9LLSWufvNYWTbTD101/Origo-Illustrasjonsbibliotek?type=design&node-id=0%3A1&t=ciKKvX723YeS8fAu-1) som du kan legge til som bibliotek eller legge inn som biblioteksfil. Det er beskrevet hvordan man legger til et bibliotek i Figma på siden [“For designere”](/grunnleggende/for-designere/kom-i-gang/).
